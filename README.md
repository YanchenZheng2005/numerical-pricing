# Numerical Methods for Derivative Pricing

Convergence, Error, and Calibration.

An ongoing self-directed project on numerical methods for pricing financial
derivatives, built from no-arbitrage and replication principles.

## Status

Stage 1 (lattice pricing engine) in progress.

## Setup

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
